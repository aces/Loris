# Data Query Tool (Beta)

Select **Define Fields** to choose the fields for your query.

Select **Define Filters** to optionally filter your results.

Select **View Data** to view your query results.

Use **Next Steps** to continue building your query.

**Recent Queries** shows your recently run queries.

**Study Queries** shows queries pinned by a study administrator.

Select ↻ to load a query.

Select ✎ to name a query.

Select ★ to star a query.

Select 📌 to pin a query.

Select 🌐 to share a query.
